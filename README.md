# エアコンクリーニング予約フォーム

町のエアコンお掃除専門店＋α（https://plus-alpha.org/）の予約リクエスト用フォームです。

- `index.html` … フォーム本体（GitHub Pages で公開）
- `apps-script/Code.gs` … 送信内容を受け取る Google Apps Script（スプレッドシートへの記録とメール通知）

## しくみ

1. お客様が `index.html` のフォームで台数・オプションを選び、概算見積もりを確認して送信します。
2. フォームは `index.html` 内の `ENDPOINT_URL`（Apps Script ウェブアプリの `/exec` URL）へ内容を送信します。
3. Apps Script がスプレッドシート「予約一覧」に記録し、店舗への通知メールとお客様への受付確認メールを送ります。

## 料金や文言を変えるとき

`index.html` の `<script>` 冒頭「設定」部分（料金・オプション・時間帯など）を編集して push してください。数分で公開ページに反映されます。

## Apps Script を変更したとき

Apps Script のエディタで保存後、「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「新しいバージョン」でデプロイしてください。
「新しいデプロイ」を選ぶと URL が変わり、`ENDPOINT_URL` の書き換えが必要になります。

## 注意

- 通知先メールアドレスは Apps Script 側（`NOTIFY_EMAIL`）にだけ設定します。このリポジトリには書き込まないでください。
